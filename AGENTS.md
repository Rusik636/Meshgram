# Работа с Git

- Перед началом работы создай отдельную ветку от актуальной локальной `main`. Если агенты работают параллельно, используй отдельный рабочий каталог Git для каждой ветки.
- После каждой выполненной задачи проверь её и создай отдельный коммит. Включай в коммит только относящиеся к задаче изменения.
- Пиши сообщения коммитов по-русски. Начинай заголовок с короткого тега и двоеточия, например `add:`, `fix:`, `delete:`, `docs:`, `refactor:` или `test:`.
- Не добавляй в сообщение или трейлеры коммита отметки о генерации ИИ, его авторстве или соавторстве.
- Главный агент проверяет ветки, вливает готовые изменения в `main`, разрешает конфликты с сохранением поведения обеих веток и повторно запускает нужные проверки.

# Сборки для устройств

- Перед сборкой нового обновления для установки на устройство увеличивай номер сборки в `mobile/pubspec.yaml`. Для Android и iOS используй один номер.

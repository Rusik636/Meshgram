# Переписка

[Общие правила V2](../MASTER.md) · [Превью](../preview.html)

Сверху располагаются заголовок беседы и капсула рации. Поле ввода остаётся у нижнего края доступной области. При увеличении высоты поля лента пересчитывает нижний отступ. У длинных слов есть перенос, отдельные абзацы сохраняются при вводе.

Сообщения одного автора группируются в пределах пяти минут и одного дня. Меньший радиус со стороны примыкания задаёт границу группы, а подпись автора канала появляется в начале группы. Лимит текста зависит от протокола и параметров кодирования. Кириллица и эмодзи учитываются по байтам.

| Событие | Представление |
| --- | --- |
| Очередь и передача своей рации | Часы или стрелка — «В очереди» или «Отправляется». |
| Подтверждение узлом | «Подтверждено адресатом». Усиленное обозначение показывается при проверяемом подтверждении Meshtastic. |
| Ретрансляция | «Подтверждено сетью» для события Meshtastic или «Ретрансляция услышана» для MeshCore. При личном сообщении использовать «Ретрансляция без ответа», если адресат ещё не подтвердил приём. |
| Ошибка | «Нет подтверждения». В пояснении доступно действие повторной отправки при наличии соединения. |
| Рация недоступна | Баннер «Нет связи с рацией», открытие выбора устройства и сохранение черновика в текущем профиле. |

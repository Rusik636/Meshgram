# Настройки и выбор рации

[Общие правила V2](../MASTER.md)

Один локальный профиль может хранить несколько раций. Строка показывает имя устройства, протокол и состояние подключения. В строке активной рации есть шкала и численное значение RSSI связи с телефоном по Bluetooth. Активные деления отображаются зелёным от −55 dBm, жёлтым от −67 dBm, оранжевым от −79 dBm и красным для более слабого сигнала. Когда измерение недоступно, шкала серая и вместо значения показывается прочерк.

Нажатие на другую сохранённую рацию переключает подключение и открывает её чаты. Свайп влево открывает действия «Отключить» и «Удалить». При удалении нужно подтвердить действие. Долгое нажатие также раскрывает действия. Локальная история доступна после отключения. Черновики и непрочитанные сохраняются для каждой рации отдельно.

Пункт «Добавить рацию» открывает радар и запускает поиск Bluetooth по всем зарегистрированным протоколам. Радар отображает уровень сигнала. При подключении ненастроенного устройства открывается мастер с шагами адаптера. Нажатие на подключённую рацию открывает параметры, доступные её адаптеру. Общий экран содержит параметры устройства. Частота, регион и параметры передачи доступны через «Настройки LoRa». Напряжение, состояние батареи и другие показания, которые передала прошивка, открываются через «Телеметрия».

При запуске и возвращении в приложение открывается соединение с последней рацией. Ручное отключение отменяет автоподключение до следующего подключения.

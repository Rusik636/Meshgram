# Дизайн-система MeshGrame V2

[Превью и каталог компонентов](preview.html) · [Токены JSON](tokens.json) · [Токены Dart](tokens.dart) · [Версия 1](../../design/index.html)

V2 задаёт интерфейс MeshGrame для iPhone. Профиль рации определяет активную сеть, историю, узлы, карту и доступность действий. Структура приложения одинакова для Meshtastic и MeshCore. Цвета, тексты и компоненты учитывают работу вне интернета, небольшие экраны и чтение при нестабильной связи.

## Метод UI UX Pro Max

Навык использован на ревизии `2de1134dc4d1cfe112934611ae5803ae17a1bd7e`. Генератор с настройками `density 7`, `motion 3` и `variance 4` дал плотность, синий акцент и рекомендации по обратной связи. Шаблон лендинга и предложенная пара шрифтов заменены на структуру мобильного мессенджера и системную типографику. Для навигации применён профиль `liquid-glass`. Видимый фокус проверяется в превью, а правила для Flutter опираются на `Semantics` и стандартные элементы управления. [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/2de1134dc4d1cfe112934611ae5803ae17a1bd7e), [материалы iOS](https://developer.apple.com/design/human-interface-guidelines/materials)

## Токены и компоненты

`tokens.json` — источник цветов, размеров, скруглений и таймингов. `export_tokens.py` синхронизирует CSS для превью и константы Dart. Цвета Dart записаны как ARGB для `Color(...)`. Flutter использует системный шрифт платформы. Размеры ниже указаны в логических единицах.

| Роль | Светлая | Тёмная |
| --- | --- | --- |
| Поверхность | `#FFFFFF` | `#1B2736` |
| Основной / вторичный текст | `#162338` / `#506078` | `#F1F6FF` / `#B6C5DB` |
| Действие | `#1852BD` | `#8DBAFF` |
| Исходящее сообщение | `#DCEBFF` | `#264869` |
| Подключено | `#17634E` на `#E4F4ED` | `#90DEC1` на `#203F39` |
| Ошибка | `#A52C45` на `#FCEAF0` | `#FFAFC0` на `#472A37` |
| Навигационный материал | `#F9FCFF` с 90% непрозрачности | `#253346` с 92% непрозрачности |

| Компонент | Контракт |
| --- | --- |
| Заголовки и текст | 32 для заголовка раздела, 17 для заголовка переписки, 16 для сообщения, 14 для превью, 12 для статуса и времени. При увеличении текста строки могут расти. |
| Строка | Базовая высота 64, аватар 48, внутренний отступ 16. Имя, время и непрочитанные имеют самостоятельные области. |
| Панель рации | Имя устройства, протокол и подписанное состояние. Выбор рации доступен из панели и из переписки. |
| Материал | Прозрачность ставится на вкладки, контролы карты, навигацию переписки и ввод. Плотный вариант использует цвет поверхности и отключает размытие. В превью включается параметром `?material=opaque` или переключателем «Плотные панели». |
| Действия | Минимальная зона касания 44 pt на iOS и 48 dp на Android. Нажатие меняет тон, не сдвигая область касания. Тайминги 100 мс для нажатия, 180 мс для выделения, 240 мс для появления листа при реализации анимации. При Reduce Motion перемещение отключается. |
| Пузырь и ввод | Радиусы 19/7 для группировки. Поле ввода минимум 48 с резервом под клавиатуру. Иконка статуса открывает текстовое пояснение и повтор там, где он предусмотрен. |
| Кнопки и листы | Собственный слой фокуса не перекрывается фиксированными панелями. Выбор имеет видимую подпись и доступное имя. Закрытие возвращает фокус на кнопку открытия. |

## Правила экранов

[Список чатов](pages/chats.md) · [Переписка](pages/conversation.md) · [Настройки и рации](pages/radio.md)

Для мобильной сборки предусмотрены две вкладки — «Чаты» и «Настройки». На экране чатов простой список с разделителями от края аватара до правого края и фильтры «Все», «Личные» и «Каналы». Индикатор плавно перемещается между вкладками фильтра и нижней панели. Новое сообщение начинается из списка чатов, а профиль открывается из шапки переписки. Настройки содержат локальный профиль, список подключений и параметры активной рации. В тёмной теме настройки используют почти чёрный фон, группы с радиусом 24, внутренние разделители и цветные иконки. Полупрозрачная нижняя панель и круглые кнопки повторяются по всему приложению.

## Реализация во Flutter

Приложение находится в `mobile/`. UI использует единые модели чатов и событий связи. Адаптеры MeshCore и Meshtastic подключаются к общему BLE-транспорту. Нижняя панель со стеклянным слайдером, фильтры чатов, основные кнопки и поле ввода iOS написаны на Swift. [Мобильное приложение](../../mobile/README.md) · [Стиль Flutter](../../mobile/lib/ui/style.dart) · [Контракт протоколов](../../mobile/lib/mesh/network.dart)

Браузерное превью выше фиксирует ранние макеты V2. В мобильной сборке чаты и настройки образуют сокращённую навигацию.

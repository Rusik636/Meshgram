# Meshgram

Самостоятельный Flutter-клиент LoRa-сетей для телефонов, планшетов и настольных компьютеров.

На широком экране список остаётся слева, а переписка и настройки открываются справа. На iPad и на macOS 26 и новее поддерживаемые элементы используют системное стекло. На компьютере папки вынесены в боковую панель, ширина списка меняется перетаскиванием разделителя, а поиск открывается по `⌘K` или `Ctrl+K`.

На главном экране два раздела — чаты и настройки. В чатах общий список с фильтрами «Все», «Личные» и «Каналы». В настройках можно изменить имя локального профиля, найти рацию по Bluetooth, переключиться между сохранёнными рациями и выбрать тему. Свайп влево по сохранённой рации открывает отключение и удаление. У активной рации рядом с именем показан RSSI подключения телефона по Bluetooth. Meshgram восстанавливает ранее открытые подключения к рациям. Выбор профиля меняет список чатов. У каждой рации свой счётчик непрочитанных и отдельное ручное отключение. Список доступных личных чатов и каналов загружается с рации. Для каждой рации сохраняются свои чаты, непрочитанные и черновики.

Экран параметров открывается нажатием на подключённую рацию. Параметры передачи находятся в «Настройки LoRa», а измерения устройства и Bluetooth — в «Телеметрия». Для MeshCore доступны имя узла и параметры LoRa, включая частоту, ширину полосы, SF, CR и мощность. Прошивка и напряжение батареи отображаются, когда устройство их сообщает. Для Meshtastic доступны имена узла, роль, регион, пресет, лимит переходов, мощность и разрешение передачи. Настройки читаются с подключённой рации. При записи Meshtastic проверяет ответным чтением, что прошивка применила значения.

Рядом со строкой ввода видны число символов и байты одного сообщения. Ответ свайпом влево и реакции из меню долгого нажатия доступны в Meshtastic для сообщений с ID пакета. Тап по фону чата закрывает клавиатуру. [Пакеты ответов и реакций Meshtastic](https://github.com/meshtastic/meshtastic-sdk/blob/main/core/src/commonMain/kotlin/org/meshtastic/sdk/RadioClient.kt)

«Добавить рацию» открывает общий экран поиска. Радар отображает измеренный RSSI, а список сортируется по сигналу. Подключение определяет первичную настройку по состоянию прошивки. Meshtastic использует ненастроенный регион, MeshCore — заводское имя узла. Шаги передаёт адаптер через `RadioOnboardingSession` и показывает общий мастер.

«Новый чат» предлагает контакты, каналы рации и поддерживаемые адаптером операции `RadioChannelSession`. MeshCore поддерживает публичный, хэштег- и приватные каналы, а также приглашения. Meshtastic добавляет приватные каналы и импортирует приглашения в свободные слоты, сохраняя основной канал и параметры LoRa. QR-код сканируется камерой. Ссылку можно ввести вручную. [MeshCore QR](https://github.com/meshcore-dev/MeshCore/blob/main/docs/qr_codes.md), [Приглашения Meshtastic](https://meshtastic.org/docs/software/apple/user/messages/)

Каталог реакций использует стандартные Unicode Emoji 17.0 и русские аннотации CLDR 48. Лицензия включена в `assets/emoji/`. [Unicode Emoji 17.0](https://www.unicode.org/Public/17.0.0/emoji/), [CLDR 48](https://github.com/unicode-org/cldr/tree/release-48/common/annotations)

## USB и прошивки на компьютере

В разделе «Настройки → Подключить по USB» выберите протокол и последовательный порт рации. Для MeshCore нужна прошивка Companion USB. Кабель должен поддерживать передачу данных.

В разделе «Настройки → Прошивки» найдите плату по названию, выберите проект и назначение прошивки. Можно загрузить официальный релиз или открыть локальный образ. Для UF2 переведите плату в режим загрузчика и выберите появившийся диск. Для ESP32 установите `esptool` версии 5 и новее. Если приложение не нашло его, укажите исполняемый файл в окне прошивки. [Установка esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32/installation.html), [релизы Meshtastic](https://github.com/meshtastic/firmware/releases), [релизы MeshCore](https://github.com/meshcore-dev/MeshCore/releases)

Иллюстрации и синонимы названий плат описаны в `assets/boards/catalog.json`. В `assets/boards/firmware.json` проекты указывают репозиторий релизов, а записи плат связывают чип и назначение с шаблоном файла прошивки. Для нового проекта с ESP32 или UF2 можно добавить записи каталога. Новый способ записи добавляется в `lib/radio/firmware_flasher.dart`.

## Слои приложения

- `lib/ui/` отображает чаты и настройки. Использует типы `Peer`, `MeshMessage` и `LinkState`.
- `lib/mesh/` содержит единый контракт сети, управление сессией и локальное хранилище.
- `lib/radio/` содержит BLE-транспорт и самостоятельные адаптеры MeshCore и Meshtastic. Новый адаптер реализует `NetworkAdapter` и `NetworkSession`, затем регистрируется в `lib/main.dart`. Экраны не зависят от UUID и форматов кадров.
- `ios/Runner/MeshTabs.swift` и `ios/Runner/MeshComposer.swift` подключают системный `UITabBarController` и нативную строку ввода iOS. `MeshControls.swift` добавляет нативные фильтры и кнопки Liquid Glass. На Android используются компоненты Flutter.

Адаптеры реализуют BLE, чтение списка узлов и каналов, приём и отправку текста и отображение подтверждений, которые сообщила прошивка. Адаптеры не обмениваются сообщениями между разными радиосетями. [MeshCore Companion Protocol](https://github.com/meshcore-dev/MeshCore/blob/75b04ef06def54b348400cb1b138afb6749ffd4f/docs/companion_protocol.md), [Meshtastic BLE](https://github.com/meshtastic/meshtastic-sdk/blob/main/docs/protocol.md), [Meshtastic Protobufs](https://github.com/meshtastic/protobufs/tree/54e071e8fade2a27c079e683c7637215491bee64)

## Сборка

Проект использует Flutter 3.47.9. `flutter test` проверяет протокольные кадры, заменяемость адаптера, раздельную историю раций и основные переходы. `flutter build apk --release --target-platform android-arm64` собирает тестовый APK. Для установки на iOS используется development-подпись Xcode с идентификатором `dev.meshgrame.client`.

Для настольной сборки запустите `flutter build macos`, `flutter build windows` или `flutter build linux` на соответствующей ОС. На macOS для сборки USB-библиотеки через CocoaPods установите `automake` и GNU `libtool`. В Linux адрес рации для Wi-Fi вводится вручную.

Флаг `--dart-define=MESHGRAME_PREVIEW=true` используется для отдельной сборки макетов. В обычной сборке список заполняется после подключения своих устройств.

### Уведомления по Wi-Fi на iOS

Local Push Connectivity связывается напрямую с подключёнными нодами MeshCore и Meshtastic. В фоне их TCP-соединения принимает расширение `LocalPush`. Оно сохраняет сообщения локально и учитывает выключенный звук в чатах. Требуется прошивка с доступным TCP-интерфейсом и одна Wi-Fi сеть для iPhone и рации.

Для сборки с этой функцией нужны App ID `dev.meshgrame.client` и `dev.meshgrame.client.LocalPush` с разрешением Apple `app-push-provider`. Оба профиля подписи должны включать App Group `group.dev.meshgrame.client.localpush`. Из каталога `mobile` запустите:

```sh
XCODE_XCCONFIG_FILE="$PWD/ios/LocalPush/Enabled.xcconfig" flutter build ios --release
```

После установки подключите рацию по Wi-Fi и задайте SSID в **Настройки → Уведомления по Wi-Fi**. Для проверки отключите интернет на точке доступа, заблокируйте iPhone и отправьте сообщение в сеть LoRa с другой рации. Проверьте появление уведомления, историю чата после разблокировки и счётчик непрочитанных в чате с выключенным звуком. [Local Push Connectivity](https://developer.apple.com/documentation/networkextension/local-push-connectivity)
